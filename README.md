# Papatya 🌼

HTML5 Canvas ile hazırlanmış, sıfırdan açılan animasyonlu papatya buketi.

## Kullanım

* **Tıkla** veya **`Space`**: Animasyonu baştan oynatır.
* **Çift Tıkla** veya **`F`**: Tam ekran modunu açar/kapatır.
* **Alt Yazı Ekleme**: URL sonuna `?text=Mesajınız` ekleyebilirsiniz (ör. `?text=Senin%20İçin`).
